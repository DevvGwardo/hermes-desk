# Relay, engine test rig

A small courier robot, not a production character candidate. Broad rounded shell,
gold antenna fins, scarf and a check-mark belly make the 40px silhouette readable.
The rig exercises nested pivots, springy ears, hands, feet, tail, hat, scarf, pupils,
all six mouth shapes, every FX type, all nine states and all three reactions.

Idle breathes and checks the cursor. Thinking tilts toward its raised hand.
Tool pumps a hand with a ring. Browsing scans. Waiting taps a foot.
Talking nods with an open mouth. Happy lifts its hands with sparkles.
Error trembles with a sweat drop. Sleep slumps with closed lids and rising z's.
