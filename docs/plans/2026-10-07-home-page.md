# Home page (launch screen)

A bare launch opens Home: Pip at 168px, centred at the top, the greeting and a one-line
status, then recent activity. There's no sidebar. Every way out returns the full shell.

## Behaviour
- **Route:** `#/home`. The selected thread underneath rides as `?c=`, like `#/routines`.
  Opening Home pushes a history entry and leaving it replaces one (`shouldPushRoute`).
- **Launch:** `launchHash()` rewrites only an empty hash, and only when the preference is on.
  Every deep link (`#/c/…`, `#/agent/…`, settings, preview) is untouched.
  Electron's `loadFile` always starts bare, so every fresh launch opens Home.
- **Preference:** `hermes-desk:home-on-launch` (`src/lib/home-prefs.ts`), on by default.
  It has its own key, so the local-prefs envelope is unchanged.
  Toggle: Settings › Appearance › Home page.
- **Shell:** stays mounted under Home inside a `display: contents` wrapper, which is set to
  `display: none` while Home is open. Drafts, scroll, transport and mascot registrations
  survive. ChatPanel/TopBar get `active={false}`, and the native workspace view is hidden.
- **Ways out:** an activity row (`selectConversation`), "Start a session" or an agent chip
  (`openAgent`), "All conversations" / "Show all conversations" (leave Home on the current
  thread), Routines, the workspace shortcuts and notification/HUD deep links.
  `selectConversation`, `openAgent` and `newConversation` all clear Home, the same way they
  clear Routines.
- **Ways back:** the sidebar Home button (`onOpenHome`), the ⌘K "Home" command, or a `#/home` link.

## Activity model (`src/lib/home-activity.ts`, pure)
- "Needs you": waiting approval or clarify, placed on that agent's newest thread.
- Then Today / Yesterday / Earlier this week / Earlier, capped at 12 rows.
- Hidden, placeholder, hidden-profile, scratch and orphaned threads are dropped.
- Preview priority: live tool line, then the newest loaded message, then the server preview.
  A preview that equals the title is never shown.
- Pip belongs to the most recently active agent. Its presence follows the live mascot state.

## Mascot engine fix
When a Pip pauses (offscreen or hidden), it now clears its stage particles instead of freezing
them on screen. Hiding the shell mid-flight exposed this.

## Activity heatmap (added 2026-10-07)
- A GitHub-style grid (`components/home/ActivityHeatmap.tsx`) sits between the hero and
  Recent activity. One column per week (Sunday first) and one row per weekday.
  It fits up to 53 weeks to the card width, with a minimum of 12.
- **Unit:** chats active per day. A chat counts once per day it was started, last active,
  had a loaded message, or was recorded in the local log.
- **Log:** `lib/activity-log.ts` (`hermes-desk:activity-log:v1`) stores conversation ids per
  day for 400 days, with no content. App records into it, debounced 1.5s, from
  conversations and loaded transcripts. This exists because Hermes only lists each
  profile's 50 most recent sessions and transcripts are not persisted.
- **Colour:** a one-hue ramp from the desk accent mixed toward the canvas, levels set by
  quartiles of the busiest day. It passed `validateOrdinal` (dark surface, from the
  dataviz skill): lightness rises monotonically, ΔL ≥ 0.06 between steps, and the
  faintest step is ≥ 2:1 against the canvas.
- **Reading it:** hover tooltip; arrow keys, Home and End move between days, announced
  through a live region; a "View as table" monthly breakdown; stat tiles for active days,
  current and longest streak, and busiest day.

## Hermes theme and backdrop (added 2026-10-07)
- **Reference:** the local Flint project (`Projects/flint`, the Jevdex GPUI app). Its welcome
  screen (`crates/flint-app/src/transcript/empty.rs`) puts `assets/welcome-coast.jpg`
  full-width at the top of the panel, cover-cropped, under a gradient that runs from
  transparent to the app background.
- **Backdrop:** `src/assets/home/hermes-coast.jpg` is that panorama re-graded by
  `scripts/bake-home-backdrop.py`. A luminance gradient map takes it onto the Hermes Teal
  ramp, and the warm light in the source becomes gold/bronze. Re-run the script to
  rebake. It sits full-bleed behind the scroller with CSS scrims: a fade into the page,
  a darker band behind the toolbar, and a soft halo behind the greeting.
- **Palette:** Hermes Agent's own colours, scoped to `.hd-home` by overriding the
  `--desk-*` tokens, so the rest of the shell is unchanged.
  - Ground and cream: `#041c1c` / `#ffe6cb`, the web dashboard's default "Hermes Teal"
    theme.
  - Gold, amber, bronze: `#FFD700` / `#FFBF00` / `#CD7F32`, the CLI default skin and the
    HERMES-AGENT wordmark.
  - All text tokens pass WCAG AA on every Home surface; the lowest pair is 4.9:1.
  - The CTA uses the wordmark's gold → amber gradient. The heatmap ramp is bronze → gold
    (`#7a4a22 #b8712c #eaa61a #ffd94a`), re-validated with `validateOrdinal`.
