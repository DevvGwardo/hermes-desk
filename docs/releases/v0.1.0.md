# Hermes Desk v0.1.0 Release Notes

**Release Date:** November 2026  
**Target Platform:** macOS (Apple Silicon arm64)

Hermes Desk `v0.1.0` is the initial packaged release of the local desktop environment for Hermes AI agents on macOS.

---

## What is Hermes Desk?

Hermes Desk is a private, local-first macOS desktop application for orchestrating and interacting with Hermes agents on your Mac. Built with Electron, React, and Vite, it pairs a native workspace interface with local `hermes serve` execution.

### Key Capabilities

- **Secure Loopback Architecture**: Connects to an authenticated loopback `hermes serve` instance. Sensitive model API tokens and credentials stay isolated within Electron's main process and never leak into the web renderer.
- **Multi-Agent Collaboration & Shared Rooms**: Chat directly with individual Hermes profiles or create shared specialist rooms with independent approval queues, durable token limits, and concurrent session tracking.
- **Bounded Generated UI (`render_ui`)**: Agents can render structured, data-only interface components (`stat`, `table`, `bar_chart`, `checklist`) via the local Hermes Desk MCP server without executing untrusted external scripts or accessing the network.
- **Interactive Pip Courier Mascot**: Built-in SVG character rig with native state poses (thinking, tool use, browsing, resting) and multiple color palettes.
- **Complete Privacy & Local Ownership**: Zero hosted update feeds, zero telemetry, and zero remote analytics. All history, rooms, and session state remain on your local filesystem.

## Installation & macOS Gatekeeper Instructions

### Step 1: Install the App

1. Download and expand `Hermes-Desk-0.1.0-mac-arm64.zip`:
   ```sh
   ditto -x -k Hermes-Desk-0.1.0-mac-arm64.zip .
   ```
2. Move `Hermes Desk.app` to your `/Applications` directory:
   ```sh
   mv "Hermes Desk.app" /Applications/
   ```

### Step 2: Clear macOS Gatekeeper Quarantine

> [!IMPORTANT]
> **Ad-hoc Code Signing Notice**: Hermes Desk releases are built from open-source code and ad-hoc signed (`--options runtime --entitlements build/entitlements.mac.plist --sign -`) without a proprietary Apple Developer ID certificate.

When you download a zip archive via a web browser, macOS automatically tags the extracted `.app` bundle with the `com.apple.quarantine` extended attribute. Because there is no Apple Developer notarization ticket attached, macOS Gatekeeper may display a warning dialog such as:

> *"Hermes Desk is damaged and can't be opened. You should move it to the Trash."*  
> or  
> *"Hermes Desk cannot be opened because Apple cannot check it for malicious software."*

#### One-Command Terminal Unlock (Recommended)

To clear the quarantine flag and allow Hermes Desk to launch normally, run this single command in Terminal:

```sh
xattr -cr "/Applications/Hermes Desk.app"
```

#### GUI Unlock Alternative

1. Open Finder and navigate to `/Applications`.
2. **Right-click** (or **Control-click**) `Hermes Desk.app` and choose **Open** from the context menu.
3. In the warning prompt that appears, click the **Open** button to authorize execution. macOS will remember this choice for future launches.

## Packaging from Source

You can reproduce this exact release artifact from source on any Apple Silicon Mac:

```sh
# Clone and prepare dependencies
git checkout v0.1.0
npm ci

# Package the release archive and compute checksums
npm run package:release
```

The script will:
1. Compile TypeScript and Vite production assets into `dist/`.
2. Package the Electron arm64 application bundle into `release/mac-arm64/Hermes Desk.app`.
3. Apply deep ad-hoc codesigning with Apple Hardened Runtime options and `build/entitlements.mac.plist`.
4. Validate strict signature integrity and `com.apple.security.cs.disable-library-validation`.
5. Create the distributable zip `release/Hermes-Desk-0.1.0-mac-arm64.zip` via macOS `ditto`.
6. Verify archive extraction integrity and write `release/SHA256SUMS.txt`.
